# 승인 프로토콜

## 사용자 승인이 필요한 일

- 실제 배포.
- 원격 저장소 push.
- destructive git 명령.
- 사용자 작업 삭제.
- 비용이 발생하는 외부 서비스 사용.
- 외부 공개와 게시.
- 인증 정보 변경.
- 큰 제품 방향 전환.

## 대표가 자율 진행할 수 있는 일

- 로컬 리서치와 기획.
- 직원에게 작업 배정.
- 로컬 구현.
- 로컬 테스트.
- `.agent-company` 기록.
- 릴리즈 체크리스트 작성.

## 승인 요청 형식

승인 요청에는 실행할 행동, 이유, 되돌릴 수 있는지, 승인하지 않을 때의 대안을 포함한다.
