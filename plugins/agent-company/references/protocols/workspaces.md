# 작업공간 프로토콜

## 상태 디렉터리

대상 프로젝트에는 `.agent-company/v2`가 생성된다. v2 상태는 회의, 메시지, 결정, 토론 서버 메타데이터만 저장한다.

기존 `.agent-company` v1 기록은 읽기 전용 legacy로 취급한다. v2는 기존 기록을 자동 변환하거나 삭제하지 않는다.

## 소스 수정

CEO, 기획자, 리서처, UI/UX 디자이너, 아키텍트, QA, 릴리즈, 기록 담당자는 소스 수정을 직접 수행하지 않는다.

풀스택 개발자는 승인된 범위의 패치 제안을 만든다. CEO가 제안을 검토하고 현재 프로젝트에 통합한다.

## 회의 서버

직원은 로컬 HTTP 회의 서버를 통해 메시지를 읽고 쓴다. 서버 URL과 토큰은 CEO가 `create_meeting` 결과에서 전달한다.

## 보안

회의 서버는 기본적으로 `127.0.0.1`에 바인딩한다. 모든 회의 API는 `X-Agent-Company-Token` 헤더를 요구한다.
